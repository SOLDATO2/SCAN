# SCAN
Spatial Channel Attention Network 

SCAN é um modelo de interpolação de frames que utiliza canais de atenção em conjunto com atenção espacial para interpolar frames.


Modelo INICIAL para apresentacao TCC com melhores pesos pode ser baixado de: [Google Drive](https://drive.google.com/file/d/1IRa2fVTsNYAnu3BqkUoNQwFn94CuW0ay/view?usp=sharing)
